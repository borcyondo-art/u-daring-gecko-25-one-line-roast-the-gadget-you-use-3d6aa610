A single original line roasting a gadget used every day, written by a
small deterministic Node program. The program writes exactly one line —
no trailing newline — to `/output/entry.txt`.

## The line

> My earbuds pause my music whenever I smile, convinced happiness is just me taking them out.

The roast targets wireless earbuds: their wear detection pauses the music
when a smile moves things around, as if happiness itself were the wearer
taking them out. It was picked from six drafted candidates and revised
twice; the draft, revised, and final wordings — and why each changed —
are documented in the comments at the top of `main.ts`.

## Run

Requires Node 22.18 or later (the grader runs Node 22.23.4):

```sh
node main.ts
```

It writes `/output/entry.txt` (1–200 characters, UTF-8, not only
whitespace, as the bounty gate requires). Running it twice produces
byte-identical output.

## Files

- `main.ts` — the entrypoint; stdlib only, no network, no secrets.
